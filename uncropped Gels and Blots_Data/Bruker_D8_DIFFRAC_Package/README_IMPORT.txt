BRUKER D8 / DIFFRAC IMPORT PACKAGE
===================================

Recommended import
------------------
For DIFFRAC.EVA, import the *.UXD file when you want the Bruker-style metadata
header retained, or use *.XY for the most robust two-column ASCII exchange.

Bruker documentation confirms DIFFRAC.EVA supports exchange to/from Bruker's
raw format and ASCII 2-column XY / 3-column XYE files.



Samples
-------
ATM_Mortar.uxd
Granite_Waste.uxd
Metakaolin.uxd

For Rietveld analysis, obtain the original Bruker .RAW/.BRML or the original
exported .XY/.XYE whenever possible.
