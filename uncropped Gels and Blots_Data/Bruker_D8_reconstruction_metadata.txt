Goniometer radius  : 217.5 mm (Bruker D8-compatible nominal value)

Intensity
---------
The image contains no original detector counts. Intensities were reconstructed
from pixel positions and scaled to a maximum of 10,000 pseudo-counts per pattern.
Therefore the files are suitable for plotting/import and preliminary peak-position
work, but NOT for quantitative intensity/Rietveld conclusions that require the
original measurement data.

File formats
------------
*.UXD  : Bruker ASCII-style scan file with Bruker-style metadata header.
*.XY   : 2-column ASCII 2theta/intensity file. DIFFRAC/EVA supports ASCII XY.
*.XYE  : 3-column ASCII 2theta/intensity/error file.
